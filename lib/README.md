# lib — third-party library

`org.json-2011-04-05.jar` is the [org.json](https://github.com/stleary/JSON-java) library (version 2011-04-05, with sources included), exactly the version bundled in the Prouesse JAR files. Prouesse uses it to read and write JSON data files. It is distributed under its own license: see [`org.json-LICENSE.txt`](org.json-LICENSE.txt). It is **not** covered by the Prouesse license.

`org.json-2011-04-05.jar` é a biblioteca org.json (versão 2011-04-05, com os fontes), exatamente a versão embutida nos arquivos JAR do Prouesse. O Prouesse a usa para ler e gravar arquivos de dados JSON. Ela é distribuída sob licença própria: veja [`org.json-LICENSE.txt`](org.json-LICENSE.txt). Ela **não** é coberta pela licença do Prouesse.
