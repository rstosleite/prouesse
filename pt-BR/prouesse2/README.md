# Algoritmo P2 — código-fonte (português)

Código-fonte Java do **Algoritmo P2** (pacote `prouesse`, em `src/prouesse/`), com comentários que remetem às seções do livro. Classe principal: `Prouesse_teste`.

- `Probl` é a superclasse que guarda os dados do problema; as classes `Module_*` implementam os módulos de busca; `Classes_acessorias` reúne classes auxiliares.
- Veja [`../README.md`](../README.md) para compilar e executar, e [`../programas`](../programas) para os programas prontos.
