# Algoritmo P1 — código-fonte (português)

Código-fonte Java do **Algoritmo P1** (pacote `prouesse`, em `src/prouesse/`), com comentários que remetem às seções do livro. Classe principal: `Prouesse5D_X`.

- `Probl` é a superclasse que guarda os dados do problema; as classes `Module_*` implementam os módulos de busca; `Editor_`, `Horar_` e `Prouesse5D_X` implementam a interface Swing e o ponto de entrada.
- Algumas classes explicadas no livro foram posteriormente substituídas por versões mais novas, mas permanecem aqui por serem descritas no livro. Veja [`ERRATA_e_DOCUMENTACAO.md`](ERRATA_e_DOCUMENTACAO.md), que também traz figuras e a documentação das variáveis.
- Veja [`../README.md`](../README.md) para compilar e executar, e [`../programas`](../programas) para os programas prontos.
