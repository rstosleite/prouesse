# Algorithm P1 — source code (English)

Java source code of **Algorithm P1** (package `prouesse`, in `src/prouesse/`), documented with comments that refer to the sections of the book. Main class: `Prouesse5D_X`.

- `Probl` is the superclass that holds the problem data; the `Module_*` classes implement the search modules; `Editor_`, `Accessory` and `Prouesse5D_X` implement the Swing interface and the program entry point.
- The online [**Appendix**](APPENDIX.md) supplements the book's documentation: errata, figures, differences between the book and the code, and documentation of the variables.
- See [`../README.md`](../README.md) for how to compile and run, and [`../programs`](../programs) for the ready-to-run programs.
